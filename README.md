# HTML 单文件刷题 / 模拟考试工具

一个**纯前端、单 HTML 文件、完全离线**的刷题与模拟考试工具。双击即用，无需安装任何环境，数据全部保存在本地浏览器。

> 本仓库**不含任何真实题库数据**，内置 10 道公开法律常识示例题用于演示。把 `index.html` 中 `const BANK=[...]` 替换为你自己的题库，即可用于任何培训、考核、备考场景。

## 功能特性

- **练习模式**：按题库文件筛选范围、顺序刷题、即时判分与解析、答对自动跳题（快速 0.5s / 正常 1.5s / 手动三档）、进度自动存档续读
- **考试模式**：从全库随机抽题组卷（题型按比例分配）、按题型分块排版、交卷自动判分、70 分合格线判定
- **AI 出题人特训卷**：内嵌一套按易错点定制的专项试卷（示例库为空时自动隐藏入口）
- **错题本**：自动收集错题、重做全对自动移出
- **分数趋势图**：每次模拟考试成绩自动记录，平滑曲线 + 合格线参考
- **诊断日志**：内置运行日志，异常时可导出排查；考试错题自动记录（题干/你的答案/正确答案）
- **数据搬运**：一键导出/导入本地数据（进度、错题本、成绩历史），跨设备同步

## 使用方法

1. 下载 `index.html`，双击用浏览器打开（Chrome / Edge / 手机浏览器均可）
2. 首页选择模式开始使用
3. 换设备时用 🐞 面板的「导出数据 / 导入数据文件」搬运进度

### 替换为自己的题库

用文本编辑器打开 `index.html`，定位 `const BANK=`，按以下 JSON 结构替换（UTF-8 编码）：

```json
[
  {
    "key": "file1",
    "title": "《你的题库文件名》",
    "cat": "分类名",
    "items": [
      {
        "n": 1,
        "t": "单项选择题",
        "stem": "题干……（ ）",
        "opts": ["选项A", "选项B", "选项C", "选项D"],
        "ans": "A",
        "jx": "解析文字"
      },
      { "n": 2, "t": "多项选择题", "stem": "……", "opts": ["…","…","…","…"], "ans": "ABD", "jx": "……" },
      { "n": 3, "t": "判断题", "stem": "……", "opts": [], "ans": "对", "jx": "……" }
    ]
  }
]
```

- `t` 支持：`单项选择题` / `多项选择题` / `判断题`（渲染时自动归一化为 单选/多选/判断）
- 多选计分：全对 2 分、漏选 1 分、错选 0 分（默认每题 2 分制，可自行修改 `score()` 函数）
- 模拟考试默认从**全部题库**随机抽题；题型配比按题库自然比例

## 技术说明

- 单 HTML 文件，零依赖、零构建、零后端，可离线使用
- 题库数据以内嵌 JSON 形式存储于 `const BANK=`
- 用户数据（进度/错题/成绩）存于浏览器 `localStorage`，不上传任何服务器
- 附带 Python 生成管线（`parse_bank.py` 解析题库原始文本 → `gen_html.py` 注入模板），可批量把 PDF/文本题库转成本工具
